# Текущее состояние

Дата обновления: 2026-11-08

## Продукт и приложение

- MVP принимает реальные MP4/WebM до 25 МБ и 10 минут, требует согласие на облачную обработку, показывает фактический прогресс и вращающийся индикатор ожидания до ответа сервера.
- Обработка извлекает аудио через FFmpeg, получает расшифровку через OpenAI-compatible API и формирует структурированные итоги только по содержанию встречи. Демо-данные не подставляются.
- Статусы, ошибки, повторная обработка и диагностика сохраняются у встречи. Для ошибок FFmpeg записывается код завершения и ограниченный хвост stderr; для AI — HTTP-метаданные и очищенное сообщение провайдера.
- Пользователь видит и редактирует только свои встречи; сервер проверяет владельца. Администратор видит все встречи и управляет доступом.
- Кнопка массового удаления находится справа от заголовка «Ваши встречи», отдельно от загрузки. Удаляются только встречи текущего пользователя и их медиа; аккаунты и приглашения остаются. Активные обработки блокируют массовое удаление.
- Сессионная cookie не имеет постоянного срока хранения. Ключ подписи ротируется при каждом старте приложения; перезапуск завершает активные входы, не затрагивая данные.
- Видео и временное аудио очищаются через 24 часа. Расшифровка и текстовые результаты хранятся до удаления встречи.

## Пилотный сервер

- Приложение опубликовано по HTTPS на `app.traineeserver.ru`; systemd, Nginx/Certbot, UFW и проверенный push → GitHub Actions → сервер настроены.
- Пилот использует одну VM Ubuntu, Python 3.12, FFmpeg/FFprobe, один Uvicorn worker, SQLite и постоянный каталог `/var/lib/meeting-analysis`.
- Владелец подтвердил, что `PILOT_DEPLOY_ENABLED=true`. Workflow на push в `main` разворачивает релиз, перезапускает службу и проверяет `/health`.
- Публичный `/health` ранее отвечал 200; `/setup` закрыт извне. Серверные аккаунты/данные отдельны от локальной базы.
- Бэкапы отложены решением владельца учебного пилота. Обработка выполняется внутри веб-процесса; если перезапуск прерывает её, встречу нужно запустить повторно.

## Проверено ранее

- Приложение импортировалось в Python 3.12; `/health` отвечал `200`.
- Реальный пользовательский MP4 загружен и обработан; расшифровка и результаты сохранены у исходной встречи, цитаты прошли дословную проверку, временное аудио удалено.
- Проверены серверные ограничения доступа для администратора и обычного пользователя, отказ анонимным API-запросам и защита первоначальной настройки.
- Автоматический deploy и переключение релиза проверены; подробная история публикации находится в [DEPLOYMENT.md](DEPLOYMENT.md).

Эти проверки относятся к указанным этапам и не заменяют проверку последнего релиза в GitHub Actions. Последние изменения считаются действующими на сервере после успешного завершения deploy workflow.

## Ещё не реализовано или отложено

- Сброс пароля и настройки программы администратора.
- Устойчивая очередь фоновых задач и масштабирование за пределы одного процесса/VM.
- Резервное копирование и проверка восстановления — отложены решением владельца.
- AI-правки результатов с предпросмотром и подтверждением, большие файлы и diarization.
