## Сейчас

Локально реализованы вход, разграничение встреч по владельцу, администрирование доступа и очистка медиа; сервер запущен. Администратор и обычная учётная запись уже существуют. Старая встреча без owner_id остаётся доступна только администратору. Добавлены редактирование данных встречи, расшифровки и структурированных результатов с серверной проверкой владельца, сводная панель и табличные строки встреч по утверждённому референсу. В строках нет фотографии и числа участников; «…» — заглушка. Сводка перестраивается в три колонки при ширине экрана до 1080 px, чтобы кнопка загрузки не обрезалась. Административная таблица использует более компактные колонки и не выходит за ширину контейнера, чтобы кнопки открытия и меню оставались видимыми. Для новых регистраций требуется имя; только администратор видит имя владельца в отдельной колонке всех встреч. Существующим аккаунтам без имени заполнено значение из части почты до «@»; заданные вручную имена сохранены. После выбора файла и явного согласия передача начинается без кнопки; обработка запускается автоматически, список обновляет её этапы. Дата встречи заполняется датой загрузки. По окончании AI-анализа редактируемые поля повестки, выводов и следующей встречи автоматически заполняются только данными с цитатным подтверждением в расшифровке.

Для подготовки публикации создан `docs/DEPLOYMENT.md`. Первый релиз опубликован по HTTPS, первоначальный администратор создан, базовая защита периметра включена, автоматическое обновление проверено. Резервные копии отложены для учебного пилота по решению владельца. Остаётся функциональная эксплуатационная проверка на сервере. Фоновые задачи привязаны к веб-процессу, а SQLite и медиа — к локальному диску.
