# Принятые решения

## Продукт

1. Сервис анализирует фактическую речь из загруженного видео; демонстрационные данные не заменяют обработку записи.
2. Язык распознавания первой версии — русский.
3. Первая учебная версия рассчитана на администратора и обычных пользователей; отдельная роль проверяющего не используется.
4. Регистрация доступна по активному многоразовому коду приглашения; публичной регистрации нет.
5. Пользователь видит и меняет только загруженные им встречи и результаты обработки. Администратор видит и меняет все встречи, а также управляет приглашениями, доступом и настройками программы и может удалять встречи. Старые встречи без установленного владельца доступны только администратору.
6. Передача аудио внешнему облачному AI разрешена. До первой отправки интерфейс должен сообщить администратору о передаче.
7. Исходное видео и временное аудио хранятся не более 24 часов; расшифровка и результаты — до удаления встречи администратором.
8. Разделение по говорящим и определение личности по голосу не входят в первую версию.
9. Последовательные AI-правки не обязательны для первой версии. Их следует учитывать при проектировании хранения и результатов; добавление планируется на будущее с предпросмотром и явным подтверждением пользователя.
10. Лимиты первой версии: MP4/WebM, не более 25 МБ и 10 минут.

## Технологии и окружение

1. Локальная разработка ведётся на Python 3.12 в `.venv`.
2. Для серверного API выбран FastAPI.
3. Репозиторий Git использует ветку `main`; `origin` настроен на `git@github.com:mytrainee-ai/Meeting_analysis.git`.
4. Базовый адрес AI API настраивается через `OPENAI_BASE_URL`; начальное значение — `https://api.openai.com/v1`. Совместимость альтернативного endpoint проверяется отдельно.
5. `.env` содержит локальные секреты и не добавляется в Git. В репозитории хранится только пример `.env.example`.
6. Первого администратора создают один раз через локальную страницу настройки; этот маршрут доступен только с loopback. Пароль должен содержать не менее 8 символов и хранится как scrypt-хеш.
7. Срок сессии локального MVP — 12 часов. Cookie подписана `APP_SECRET_KEY`, имеет HttpOnly и SameSite=Lax; для HTTPS выставляется `COOKIE_SECURE=true`.
8. Код приглашения многоразовый до отзыва; в БД хранится SHA-256-хеш, исходный код показывается администратору только при создании.

## Открытые решения

- Выбор и тариф Linux-хостинга Timeweb Cloud.
- База данных, очередь фоновых задач и объектное хранилище для развёрнутого приложения.
- Точный идентификатор поддерживаемой модели у выбранного AI endpoint и оценка расходов.
- Сброс пароля и управление им после первоначальной настройки.
- Точный текст уведомления о внешней обработке и требования к браузерам.

## Дизайн учебной версии

1. Предусмотрены три экрана: обзор, встреча, загрузка/обработка.
2. На обзоре и в карточке встречи показываются пустые состояния, без демонстрационных встреч и результатов.
3. Этап загрузки поддерживает MP4 и WebM, показывает фактический прогресс и ошибки, позволяет отменить активную передачу и вернуться к списку встреч. После успешной загрузки показывается кнопка «Открыть встречу».
4. Загрузка по внешней ссылке отложена; возможность добавления ссылок (например, Google Drive/Dropbox) учитывается как будущее расширение.
