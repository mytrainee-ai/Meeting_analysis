# Правила работы с проектом

- Перед изменениями изучай `docs/03-prd.md`, `docs/DECISIONS.md` и `docs/CURRENT_STATE.md`.
- Требования продукта фиксируются в PRD и принятых решениях. Если новое решение меняет их, сначала уточни его у владельца проекта.
- После каждого завершённого этапа обновляй `docs/CURRENT_STATE.md`; изменения направления развития отражай в `docs/ROADMAP.md`.
- Секреты хранятся только в локальном `.env`. Не выводи значения секретов в консоль, журналы или ответы; в Git добавляй только `.env.example` без секретных значений.
- Для локальной разработки используй Python 3.12 и виртуальное окружение `.venv`.
- Проверяй полномочия на сервере, а не только в интерфейсе.
- Не подменяй обработку пользовательских видео демонстрационными данными.
